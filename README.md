# 見開きリーダー

見開き2ページを1枚の写真として取り込んだPDFを、Android と Windows で1ページずつ読むための PWA。
Google ドライブから開き、表示上のみ左右に分割して、画面にフィットさせて表示する。

- 要件: [docs/requirements.md](docs/requirements.md)(第2版・最終)
- セットアップ: [docs/setup.md](docs/setup.md)
- 実装での判断・要確認事項: [docs/design-notes.md](docs/design-notes.md)

## 開発状況

| 段階 | 内容 | 状態 |
|---|---|---|
| 第1段階 | ドライブから開く、左右分割、フィット表示、ページ送り、再接続、データ形式 | 実装済み(実機・実データでの確認待ち) |
| 第2段階 | ズーム、余白トリミング、横長2ページ、オフライン保存、読書位置 | 実装済み(実機・実データでの確認待ち) |
| 第3段階 | 端末間同期、サムネイル、名前つきページ、ページジャンプ | 未着手 |
| 第4段階 | メモ、蛍光ペン、出力 | 未着手 |

## コマンド

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト
npm run build      # 型検査 + 本番ビルド
```
