## 同期体験の改善(利用者のフィードバックを受けた変更)

「両方を開いているときにどちらがどちらに反映されるか分かりにくい」「再接続の手間」「反映されない・遅い」への対応。

| 課題(原因) | 対応 | 区分 |
|---|---|---|
| 他の端末の変更を、開いたままの端末が取りに行かなかった(自分の変更時にしか同期しなかった) | 開いている間は30秒ごと、画面に戻ったとき、フォーカス時、ネットワーク復帰時に確認する。ドライブ上のファイルの版が変わっていなければ、本体は読み込まない(通信量の削減) | 判断 |
| 「同期済み」が「自分の変更を送った」だけの意味で、最新かどうか分からなかった | 「最新(10:42に確認)」と、ドライブ上の状態を確認できた時刻で表示。取り込み・送信は「↓他の端末から しおり・目次1件 を取り込み」「↑1件を送信」と、方向と内容を8秒間表示する | 判断 |
| 他の端末の読書位置が分からない(開く前の同期でしか反映されない) | 他の端末の位置の方が新しいとき、「他の端末の読書位置: p.45 [移動]」と尋ねる。**表示中のページは勝手に動かさない** | 判断 |
| アクセストークンがメモリ上だけで、アプリを開き直すたびに接続が消えた | **有効期限(約1時間)の間だけ、トークンを端末内(localStorage)に保存**し、開き直しても接続を引き継ぐ。期限切れ・401・「この端末の接続情報を消す」で即座に消す。権限はアプリ専用領域と選んだPDFに限られる | 利用者が採用を承認(2026-11-13)。**この端末を他人が使える状態だと、期限内は悪用される余地がある** |
| 未接続の状態では、再接続ボタンが出なかった(切れた後にしか出ていなかった) | 未接続でも「ドライブに接続」、切れたときは「再接続」を常に表示 | 不具合の修正 |
| 再接続に、メニューを開いてボタンを押す手間がかかった | 接続が切れたあと、**次の画面操作で自動的に再接続を試みる**(設定でオフにできる)。失敗・キャンセルしても繰り返さない。Googleのスクリプトは起動時に先読みし、ポップアップを操作の直後に開けるようにする | 判断。**実際のGoogleでの動作(ポップアップの出方)は未確認** |
| 1時間ごとの再接続そのものは残る | サーバーを持たない構成では、Googleが自動更新を許していないため、仕様として残る。再接続の手間を減らすのみ | 制約 |

## 位置の同期の不具合修正(2026-11-13)

| 症状 | 原因 | 対応 |
|---|---|---|
| PC側は「スマホの位置へ移動しますか」と出るが、スマホ側はPCの移動を受け取らない | 最後に読んだ位置を、ページを移動したときだけでなく、画面サイズの変化・画面を隠す・閉じるたびに「いま」の時刻で保存し直していた。「新しい方が勝つ」ため、操作していないスマホの古い位置が、PCの新しい位置を上書きした | 利用者がページを移動したときだけ保存する。再現手順を操作テストに追加し、修正前に失敗・修正後に成功することを確認 |
| スマホが古い版のまま動いている可能性(確認できていない) | 配信後の初回は旧版が表示される(サービスワーカー) | 設定と開始画面に「バージョン(コミットID)」を表示。新しい版が来たら「新しい版があります [更新]」を表示。画面に戻ったときに新しい版を確認する |

**残る不確かさ(事実として未確認)**: 端末どうしの時計のずれ。位置・設定は端末の時計で「新しい方」を決めるため、時計が大きくずれた端末では、古い操作が勝つ可能性がある(サーバーを持たないため、補正の手段が限られる)。

### 未対応・制約(第4段階)
- メモの一覧・検索の画面は無い(書き出したMarkdownで見渡す)。
- 蛍光ペンの色・太さの後からの変更は不可(消して引き直す)。
- 書き出しで、注釈が無くなったページの古い画像は、ドライブ上に残る(消さない)。
- Markdown内の画像は相対パス。ドライブの画面上のプレビューでは表示されない場合があり、フォルダごとダウンロードすると表示できる。

## 第4段階の体験改善(利用者のフィードバックを受けた変更)

質問(2回)への回答: 付ける操作は「線がカクカクする・細かい調整ができない」「注釈モードに入る・ツールを切り替える手間」「間違いを元に戻せない」、見返す・書き出すは「一覧で見られない」「書き出しの手順」「書き出し結果の内容・見た目」。入口は「右クリックで蛍光ペン・メモ」「読書中の長押しでメモ」。一覧は「ページ順・タップで移動」「文字検索・種類/色で絞り込み」「一覧から編集・削除」「目次(章)ごとにまとめる」。書き出しの手順・見た目は「こだわりなし」。

| ご要望 | 対応 | 区分 |
|---|---|---|
| 線がカクカクする | 取りこぼした途中の点も使い(`getCoalescedEvents`)、**滑らかな曲線**(隣り合う点の中点を通る二次曲線)で描く。描いている途中から仕上がりと同じ形で見せる。保存時は手ぶれの点を間引く(許容: 画面上1.5px)。書き出し画像にも同じ規則を使う | 判断 |
| 細かい調整ができない | 自由線の**太さ(細・中・太)**を選べる。蛍光ペンの**色**は一覧から後から変えられる | 判断 |
| 間違いを元に戻せない | **元に戻す/やり直す**(ツールバーのボタン、Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z)。作成・消しゴム・メモの編集・削除が対象で、最大50件、本を閉じると消える。**削除の印の付け外しで表す**ため、同期で他の端末の変更を巻き戻さない | 判断 |
| 右クリックで蛍光ペン・メモ | PCで右クリックすると、「ここにメモを置く」「蛍光ペン(四角で囲む)」「蛍光ペン(なぞる)」と色のメニューが出る。蛍光ペンは**1回だけ描いて閲覧に戻る**(注釈モードには入らない)。メニューを閉じるための外側のクリックは、ページ送りにしない | 利用者の回答を解釈 |
| 読書中の長押しでメモ | タッチ・ペンで、ほとんど動かさず約0.55秒押すと、その場でメモの入力欄が開く。**注釈モード中は無効**(描画の邪魔をしない)。動かすとスワイプ、短いタップは今までどおり | 利用者の回答どおり |
| 注釈の一覧 | 移動画面に「注釈」タブを追加。ページ順、行のタップでそのページへ移動、**文字検索**(メモの本文・蛍光ペンのOCR文字・ページ表記)、**種類・色で絞り込み**、**目次(章)ごと**に見出し(切り替え可)、メモの編集・色の変更・削除。蛍光ペンの文字は、文字データのあるPDFで後から読み込む(検索は読み込み後に効く) | 利用者の回答どおり |
| 書き出し | 注釈の一覧画面から直接書き出せる(設定画面からも従来どおり)。Markdownは、目次があれば**章を見出し(##)、ページを小見出し(###)**にする。最初の目次より前のページは「(章の前)」 | 回答が「こだわりなし」のため判断 |

### 判断を要した点・制約
- 「右クリックで蛍光ペン・メモを入力できる」は、選択肢にない自由記入の回答だったため、上のメニューとして解釈した。意図と違えば変更する。
- 蛍光ペンの**四角の位置・大きさの後からの調整**(ハンドルでの変形)は未対応(消して引き直す。元に戻すは可)。
- 一覧のOCR文字は、PDFに文字データが無ければ出ない(行には「蛍光ペン(四角)」と表示する)。
- 右クリックメニューはマウスのみ。タッチでは長押し(メモのみ)。タッチで蛍光ペンを引くには、従来どおり注釈モード(✎)に入る。
- 長押しの時間(0.55秒)、線の間引き(1.5px)、太さの値(細0.6%・中1.2%・太2.4%)は仮置き。

### 制約・未確認
- **精度は、合成した画像での確認のみ。** 撮影写真(影・ゆがみ・ルビ・小さな文字・縦書きの複雑な組み)での精度は未検証。実機で試し、不十分なら、ドライブ方式(案B)を追加する(承認済みの方針)。
- **SIMD対応のブラウザが必要。** core は SIMD 版(約3.9MB)だけを配っている。古い端末・ブラウザでは、読み取りの準備に失敗する(手入力は使える)。
- 処理時間は、デスクトップで1件あたり約1〜2秒(合成画像)。スマホでの時間・メモリは未確認。
- 古い版のアプリが残る端末は、`ocrText` を知らないため、同期のときに文字を落とす可能性がある。更新後に使うのが安全。
- リポジトリは約5MB増える(学習データ)。
