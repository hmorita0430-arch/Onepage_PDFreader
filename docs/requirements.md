# 見開きPDFリーダー 要件定義書(第1版)

> 状態: ドラフト(要件ヒアリングの回答を整理したもの。利用者の確認待ち)
> 注意: 本リポジトリは **コードのみを公開する前提**。書籍の内容(PDF・サンプル画像)、注釈、しおり、出力ファイルは **決してコミットしない**(`.gitignore` で除外)。

---

## 1. 目的

手製の電子書籍(見開き2ページを1枚の写真として取り込んだPDF)を、AndroidとWindowsで **1ページずつ、適度な拡大で** 快適に読めるリーダーを作る。

## 2. 前提(事実)

| 項目 | 内容 |
|---|---|
| 入力 | 見開き1枚の写真が、PDFの1ページ分になっている |
| 規模 | 1冊100〜300ページ、30〜60MB程度 |
| PDFの中身 | 画像のみ(文字データなし)と仮定 |
| 保存場所 | Googleドライブ |
| 利用者 | 自分専用 |
| 対象端末 | Android、Windows |

## 3. 確定した機能要件

### 3.1 表示
| ID | 要件 |
|---|---|
| D-1 | 見開き画像を、**表示上のみ** 左右に分割する(PDF自体は加工しない) |
| D-2 | 分割位置は画像の中心を基本とし、**手動で調整** できる。設定は本ごとに保存 |
| D-3 | 開き方向(右開き/左開き)を **本ごとに** 設定できる |
| D-4 | 1ページを **画面にフィット** して表示する |
| D-5 | 余白は **本ごとの共通枠** で自動トリミングし、**ページ単位の手動調整** もできる |
| D-6 | 縦長画面は1ページ表示。横長画面は設定で **1ページ/2ページ** を選べる |
| D-7 | 本ごとに **開始ページのずれ**(例: 1枚目は片側のみ=表紙)を設定できる |
| D-8 | ピンチ、ダブルタップ、マウスホイールで手動ズームできる |
| D-9 | ページを送るたびに、**フィット表示へ戻る** |

### 3.2 操作
| ID | 要件 |
|---|---|
| O-1 | 画面の **左右の端をタップでページ送り**、**中央をタップでメニュー表示/非表示** |
| O-2 | 左右どちらが「次」になるかは、開き方向の設定に連動する |
| O-3 | スワイプ、キーボードの矢印キーでもページ送りできる |
| O-4 | 注釈ツールの使用中は、タップによるページ送りを無効にする |

### 3.3 ナビゲーション
| ID | 要件 |
|---|---|
| N-1 | しおり(最後に読んだページの記憶) |
| N-2 | ページジャンプ |
| N-3 | サムネイル一覧 |
| N-4 | 目次: **自分で手作業登録**(例: 「第3章=45ページ」)。PDF内の目次データの読み込みは対象外 |

### 3.4 注釈
| ID | 要件 |
|---|---|
| A-1 | 蛍光ペン: **矩形指定** と **自由線** をツールバーで切り替える。色は数色から選択 |
| A-2 | メモ/付箋: 区別せず **1種類の「位置つきメモ」**。ページ上の任意の位置に貼り、タップで文章を開く |
| A-3 | 注釈は **PDF本体を書き換えず、別データとして保存** する。座標は、分割・トリミングの設定変更に影響されにくい形式(元画像基準の正規化座標)で保持する |
| A-4 | 出力: **Markdown**(ページ番号+メモ内容)と **注釈を重ねた画像** を併用する |
| A-5 | 出力は **いつでも** 実行でき、**Googleドライブのアプリ専用領域に直接保存** する |

### 3.5 Googleドライブ連携・保存
| ID | 要件 |
|---|---|
| G-1 | PDFは、**Googleの標準ピッカーで1冊ずつ選んで** 開く。本棚機能は持たない |
| G-2 | しおり・注釈・目次・本ごとの設定は、**AndroidとWindowsの間で同期** する(ドライブ上のアプリ専用領域に保存) |
| G-3 | ログインの有効期限が切れた場合は、**再ログイン** で対応する |
| G-4 | 開いた本は **自動で端末に保存** し、次回からオフラインで読める。保存済みの本の一覧・使用容量の表示・削除ができる |
| G-5 | 同期データの形式は、第1段階から同期を前提に設計する |

## 4. 非機能要件・方針

| 項目 | 内容 |
|---|---|
| 形態 | **PWA(Webアプリ)**。AndroidとWindowsの両方で動作 |
| 公開 | **GitHub Pages**(コードのみ公開) |
| 秘密情報 | クライアントシークレット等をコードに含めない設計。`.gitignore` でPDF・注釈・出力を除外 |
| 性能 | 表示中のページと前後のページのみを読み込み、大きなPDFでも軽快に動作させる |
| 範囲外(後回し) | 夜間モード、明るさ調整、反転表示 |

## 5. 開発の段階

| 段階 | 内容 |
|---|---|
| 第1段階 | ドライブから開く、左右分割、1ページずつフィット表示、ページ送り(同期を前提にデータ形式を設計) |
| 第2段階 | ズーム、余白の自動トリミング、横長画面の1ページ/2ページ切り替え、オフライン保存、しおり |
| 第3段階 | 端末間の同期、サムネイル、目次、ページジャンプ |
| 第4段階 | メモ、蛍光ペン、付箋、読了後の出力(Markdown+画像) |

## 6. 事実と留意点

- 個人利用でアプリを公開申請しない場合、Googleのログインの有効期限が **約7日** になる仕様と理解している。実装時にGoogleの最新の説明を確認する。
- ブラウザのオフライン保存領域は端末の空き容量に依存し、上限に近づくとブラウザが自動削除する場合がある。この対策として、保存済みの本の一覧と削除機能を設ける。
- 文字データのない画像PDFでは、文字単位の選択はできない。

## 7. 未決事項・仮置き

| 項目 | 仮置き |
|---|---|
| サンプルPDFの添付 | 利用者が10〜20ページの抜粋をセッションに添付する予定(リポジトリには置かない) |
| 注釈の色数・色 | 黄・緑・ピンク・青の4色(変更可) |
| キーボードの割り当て | 矢印キーで前後、Home/Endで先頭/末尾(変更可) |
| 画面の言語 | 日本語のみ |
| 出力先の詳細 | ドライブのアプリ専用領域。保存先フォルダの指定方法は実装時に決定 |
| PDFの中身 | 画像のみ(文字データなし)と仮定。誤りなら要確認 |
